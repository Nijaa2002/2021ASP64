# Transcriptomic Analysis of Lung Cancer and Adjacent Normal Lung Tissue

## Project overview

This R/Bioconductor project investigates differential gene expression between lung tumour and adjacent normal lung tissue using the public NCBI GEO dataset **GSE19804** (Affymetrix Human Genome U133 Plus 2.0 Array, GPL570).

The nine supplied raw CEL files (**GSM494667–GSM494675**) are **adjacent-normal** samples, not a mixture of tumour and normal samples. They are processed separately with Robust Multi-array Average (RMA) for quality control. The tumour-versus-normal comparison uses the processed expression matrix and sample annotations retrieved from the full public GSE19804 series.

## Workflow

1. Validate the nine compressed CEL files in `data/raw_CEL/`.
2. Decompress them temporarily and perform RMA preprocessing using `affy`.
3. Generate CEL-subset boxplots, sample-correlation heatmap, and PCA.
4. Retrieve GSE19804 expression and phenotype data using `GEOquery`.
5. Identify tumour and adjacent-normal samples from GEO annotations.
6. Explore the full cohort using expression boxplots and PCA.
7. Fit a `limma` linear model and apply Benjamini–Hochberg multiple-testing correction.
8. Annotate probe IDs where possible and save differential-expression tables, a volcano plot, and a top-30-probe heatmap.
9. Save the analysis summary and R session information.

## How to reproduce

1. Install R and optionally RStudio, then open `Lung_Cancer_Bioinformatics_Project.Rproj`.
2. In the R console, with the project folder as the working directory, install dependencies:

   ```r
   source("code/install_packages.R")
   ```

3. Run the analysis:

   ```r
   source("code/run_analysis.R")
   ```

4. To render the R Markdown report, run:

   ```r
   rmarkdown::render("report/ICA3_Bioinformatics_Report.Rmd")
   ```

Internet access is required to retrieve the GEO series and install any missing packages. The report source (`.Rmd`) is included in the uploaded archive; a rendered HTML report was **not** present in that archive.

**Note:** The analysis script's final console message mentions `report/Bioinformatics_Report.Rmd`, but the actual report filename in this project is `report/ICA3_Bioinformatics_Report.Rmd`. Use the latter when rendering.

## Interpretation and limitations

The analysis identifies probe sets associated with differences between tumour and adjacent-normal samples. The nine supplied CEL files alone cannot support a two-group differential-expression comparison. The full-series processed expression data and separately RMA-processed nine-sample subset should not be combined as though they were generated by the same preprocessing run. The analysis uses an unpaired group comparison; clinical pairing and other covariates are not modelled. Probe-level results may map to multiple genes, and statistical significance does not demonstrate causation or clinical utility. Findings require independent biological validation.
